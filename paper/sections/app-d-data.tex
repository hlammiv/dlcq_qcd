\section{Data and code availability}
\label{app:data}

Both solvers are public: the preserved 1988-era Fortran, unmodified, and
the Python port.  The repository also carries every analysis script, the
digitized markers of all 1990 figure panels with their axis-calibration
provenance, and the per-figure data files.  Each data file records in its
header the exact command that regenerates it.

Every number in this paper's prose is a macro generated from those data
files by a single extractor.  The extractor records the repository revision
and input hashes alongside the values.  Every figure is built by a single
driver that reads cached solver output and refuses to solve; a missing
input surfaces as an explicit run command, not a silent recomputation.  The
equal-time exact diagonalization used for the Schwinger-model cross-checks
of Sec.~\ref{sec:modern} is included.  All of it lives at
\url{https://github.com/hlammiv/dlcq_qcd}.
